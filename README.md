# SCIENTIFIC-CALCULATOR
Scientific Calculator

This project is a simple and beginner-friendly Scientific Calculator developed in C++. It allows users to perform basic arithmetic operations as well as various scientific calculations.

Features

Addition
Subtraction
Multiplication
Division
Square Root
Power
Sine
Cosine
Tangent
Logarithm

The project is designed to help beginners understand C++ programming, functions, conditional statements, and mathematical operations.

Technology Used

C++
Standard C++ Math Library
